# Security policy

## Scope

This utility intentionally communicates with a physically connected, owner-controlled camera over a local UART and isolated Ethernet network. It does not require cloud credentials and does not transmit telemetry.

## Reporting a vulnerability

Please open a GitHub security advisory instead of a public issue when a report could put users or devices at risk.

Do not include camera passwords, serial numbers, MAC addresses, private network diagrams, or unredacted recovery logs in public reports.
